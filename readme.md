# TechFlow — Project Management Dashboard

Dashboard web desenvolvido para a TechFlow, uma empresa fictícia que busca centralizar o acompanhamento de projetos, equipes, tarefas e indicadores em uma única interface.

O projeto faz parte do **Checkpoint 5 — FrontEnd Design 2026-2** e tem como foco a construção de uma interface responsiva, com atenção à organização visual, usabilidade e interatividade.


## Integrantes

* Diego Caio de Ulhôa | RM: 572190
* Lucas Dos Santos Oliveira | RM: 571718


## Visão geral

A proposta é reunir informações importantes para facilitar o acompanhamento dos projetos e tornar a navegação mais intuitiva, com uma interface adaptável a diferentes dispositivos.

## Funcionalidades

* **Dashboard:** visualização de indicadores e informações dos projetos.
* **Gestão de projetos:** organização de projetos por status e informações relevantes.
* **Cadastro de projetos:** formulário com campos para registrar novos projetos.
* **Pesquisa:** localização de projetos por meio de um campo de busca.
* **Navegação responsiva:** adaptação dos componentes para dispositivos móveis e desktops.
* **Interações de interface:** menus, estados visuais e transições.
* **Temas:** suporte às opções Light, Dark e System, conforme a implementação do projeto.

## Tecnologias utilizadas

* **HTML5** — estruturação e organização do conteúdo.
* **Tailwind CSS** — estilização, layout e responsividade.
* **JavaScript** — implementação das interações e da lógica da interface.
* **Git e GitHub** — versionamento e gerenciamento do código-fonte.
* **GitHub Pages** — publicação da aplicação web.

## Estrutura do projeto

```text
cp5-frontend/
├── index.html
├── css/
│   └── styles.css
├── js/
│   └── app.js
└── README.md
```

## Como executar localmente

1. Clone o repositório:

   ```bash
   git clone https://github.com/luczss/cp5-frontend.git
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd cp5-frontend
   ```

3. Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server no Visual Studio Code.

   Caso o projeto utilize um processo de build ou dependências locais, siga as instruções correspondentes à configuração existente.

## Objetivos de desenvolvimento

O projeto explora conceitos fundamentais de desenvolvimento Front-End, incluindo:

* Construção de layouts com Flexbox e CSS Grid.
* Desenvolvimento orientado ao conceito Mobile-First.
* Aplicação de breakpoints para diferentes tamanhos de tela.
* Implementação de estados de interação e microinterações.
* Manipulação do DOM com JavaScript.
* Gerenciamento de temas e persistência de preferências.
* Organização e separação dos arquivos da aplicação.
